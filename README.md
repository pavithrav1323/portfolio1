# Pavithra V Portfolio

A clean, interactive, responsive one-page portfolio built with HTML, CSS and JavaScript.

## Files

- `index.html` — Portfolio content and section structure.
- `style.css` — Responsive layout, light/dark theme and visual styling.
- `script.js` — Theme toggle, mobile menu, scroll reveal, active navigation and project filtering.

## Run locally

You can open `index.html` directly in a browser.

For a local development server, you can also use VS Code Live Server.

## Deploy on Vercel

1. Create a GitHub repository.
2. Upload these three files.
3. Import the repository into Vercel.
4. Deploy as a static site.

## Important edits before deployment

In `index.html`, replace the `#` placeholders in the LinkedIn and GitHub contact links with your actual profile URLs.

You can also add:
- A real profile photograph.
- Resume download button.
- GitHub project links.
- Live project demo links.
- A working backend/email service for the contact form if you decide to add one later.
